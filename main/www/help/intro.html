Fieldwork order

Download and upload GPS tracks first, then enter observations. After saving, use views, the nest map, and downloads to check what the database now says.

Controlbar (upper right)

Set the reference date, change nest map text and symbol size, and filter nest states.

Press Set after changing the date. The date is saved in the database, and all database views use it.

Downloads

Install the app on this device, download the to-do PDF, export an offline nest KMZ, export offline interactive tables, or download the full database as an *.RDS file.

Overview

Check the season summary plot. It uses the current reference date.

GPS

Open the GPS upload/download app. Use it before data entry so GPS tracks can be matched to observations.

Enter Data

Enter new field observations, check validation issues, and save them to the remote database.

Apps: OBSERVERS for observer names/codes; CAPTURES for captures, measurements, tags, samples, and photos; NESTS for nest visits and states; EGGS for egg records; RESIGHTINGS for field resightings; RESIGHTINGS_PUBLIC for external/public resightings; inspectors for validation rules.

Show Tables

Inspect raw database tables. Use this when you need to check exactly what was saved after entry.

Show Views

Views are virtual tables. They contain no data themselves. They combine, clean, and reshape saved data for fieldwork. They feed the to-do PDF, nest map, KMZ export, and offline tables export. Source: views.SQL.

Database

Open the database interface when existing saved data needs a direct edit. Use Enter Data for new records.

Nest Map

View the latest nest locations from NESTS_LATEST. In the controlbar, use Nest state to filter nests and Text and symbol size to change map labels and symbols.
