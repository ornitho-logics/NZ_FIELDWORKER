### Fieldworker at a glance

<div class="intro-help-items">
  <div class="intro-help-item">
    <strong>Controlbar</strong>
    <span>
    The right side bar. Set the <code>reference date</code>, adjust nest map text, symbol size, and nest states.
    The <code>reference date</code> is set in the database. Remember to updated it whenever is necessary.
    All the database Views are defined relative to the <code>reference date</code>.
    </span>
  </div>

  <div class="intro-help-item">
    <strong>GPS</strong>
    <span>
    Upload/download GPS tracks and check GPS setup.
    </span>
  </div>

  <div class="intro-help-item">
    <strong>Enter Data</strong>
    <span>
    Enter new field observations.
    </span>
  </div>

  <div class="intro-help-item">
    <strong>Show tables</strong>
    <span>
    Inspect raw database tables.
    </span>
  </div>

  <div class="intro-help-item">
    <strong>Show Views</strong>
    <span>
    Views are saved database queries that combine, clean, and reshape raw records into tables usefull for fieldwork. Downstream they feed the to-do PDF, nest map, KMZ, and tables export.
    The source of the Views: <a href="https://github.com/ornitho-logics/NZ_FIELDWORKER/blob/main/DATABASE/views.SQL"
  target="_blank" rel="noopener noreferrer">views.SQL</a> 
    </span>
  </div>

  <div class="intro-help-item">
    <strong>Database</strong>
    <span>
    Open the database interface for edits.
    </span>
  </div>

  <div class="intro-help-item">
    <strong>Nest Map</strong>
    <span>
    View latest nests.
    </span>
  </div>

  <div class="intro-help-item">
    <strong>Downloads</strong>
    <span>
    Export the to-do PDF, nest KMZ, and tables HTML.
    </span>
  </div>

</div>
