Upload your GPS first

Important: Please upload your GPS before entering any data.

Work at the same time

Multiple people can enter data simultaneously. You do not need to wait for someone else to finish.

Use column hints

Hover over column names to see what each column means and how the value should be entered.

Use shortcuts when useful

Check keyboard shortcuts. Most common Excel shortcuts work here too. They are optional, but they make data entry faster.

Save when finished

Click SAVE to upload the new data to the database. Hold Ctrl while clicking SAVE to open the menu.

Fix validation issues

The data is checked before upload. If saving is blocked, open DATA ENTRY ISSUES and fix the listed problems.

If an issue cannot be solved in the entry form, set VALIDATION to OFF. Add a comment explaining why validation was bypassed.
