Where the data lives

Data entered in the app is saved to the database on the server hosting this page. This server is remote from your computer.

Back up before making changes

Before making any change to the database, download a database copy in case you need to revert your changes.

Edit existing data

Use the Database interface when you need to edit records that already exist in the remote database.

View or download data

Use Show tables and Show views to inspect the data in the app. Use Downloads to download the database as an *.RDS R file or an *.sql database copy.
