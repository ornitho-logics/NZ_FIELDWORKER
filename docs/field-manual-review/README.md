# Field Manual review drafts

These documents are proposed reading aids for experienced team members, not
replacements for the [current app manual](../../main/www/field-manual/manual.md).
Luke Eberhart-Hertel requested their inclusion in the reviewed repository branch.

- [Core Team Field Guide](core-team-field-guide.md): concise daily procedures,
  capture restrictions, and links to the detailed requirements. It explicitly
  explains why comments cannot replace separate event records used by the To-Do
  algorithm, including NESTS comments versus a bird's RESIGHTINGS record.
- [Section-by-section relocation checklist](relocation-checklist.md): proposed
  destinations for all existing chapters, appendices, and the AI-use disclosure,
  with safeguards against losing requirements during shortening.

The full app manual remains the detailed reference. No sections have been moved,
and neither the app's reading interface nor its default manual has been replaced
by these drafts. Their page-length target has not been verified in a print layout.
The documents contain no field records. Existing approved source changes and
their verification limits are documented separately in the
[parent-association contract](../reconstruction/PARENT_ASSOCIATION_CHRONOLOGY.md).

Before restructuring the published manual, review these drafts, preserve every
unique rule and exception, and check links and generated HTML. Removing or
revising these review documents does not require any database change.
